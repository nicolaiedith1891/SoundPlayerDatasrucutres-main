# SoundPlayer 🎵

**SoundPlayer** is a Java-based music player application built with **NetBeans IDE**. This project demonstrates the fundamental functionalities of a music player while integrating **data structures and algorithms** for efficient music management and playback.

---

## 🚀 Features
- 🎼 **Play, Pause, Stop** music files
- 📂 **Load & Manage Playlist**
- 🔁 **Loop & Shuffle Modes**
- ⏩ **Next & Previous Track Navigation**
- 📊 **Implementation of Data Structures & Algorithms**

---

## 🛠 Technologies Used
- **Java** (Core functionality & GUI)
- **Swing & AWT** (Graphical User Interface)
- **Java Sound API** (Audio playback)
- **Data Structures** (Queues, Stacks, Linked Lists for playlist management)

---

## 📜 How to Run
1. **Clone the repository**
   ```sh
   git clone https://github.com/nicolaiedith1891/SoundPlayer.git
   ```
2. **Open in NetBeans IDE**
3. **Build & Run the project**
4. **Load music files and enjoy! 🎶**

---

## 💡 Data Structures & Algorithms Used
- **Linked Lists** → Efficiently manage song queue.
- **Stacks** → Implement "Previous Song" functionality.
- **Queues** → Handle playlist sequence.
- **Sorting Algorithms** → Sort songs based on metadata.
- **HashMaps** → Store song metadata for quick retrieval.
